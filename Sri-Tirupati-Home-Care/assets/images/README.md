This project currently uses placeholder photography (picsum.photos) so the
site works out of the box with no setup. For production, drop your own
photos into these folders using the same file names referenced in the HTML,
or update the `src` attributes to point at your final assets:

- logo/       → your business logo + favicon
- hero/       → homepage hero banner photography
- services/   → one photo per service card
- gallery/    → photos for the gallery page
- staff/      → team photos for the About page
- testimonials/ → client photos for reviews
- icons/      → favicon.png and any custom icon assets
